# 웹툰뷰어 (Android)

세로로 아주 긴 이미지(웹툰, 긴 캡처 등)를 **휴대폰 가로 폭에 꽉 맞춰** 위아래로 **스크롤**해서 보는 간단한 안드로이드 앱입니다.

## 기능

- 이미지 열기: 오른쪽 위 🖼 버튼으로 **여러 장**을 한 번에 고르거나, 📁 버튼으로 **폴더**를 통째로 열기
- 여러 장은 **파일 이름 순서**로 빈틈없이 이어 붙임 (`2화.jpg` 가 `10화.jpg` 보다 앞)
- 각 이미지를 화면 가로 폭에 맞춰 확대/축소 → 위아래 스크롤로 감상
- 세로 수만 픽셀짜리 이미지도 열림: 화면에 보이는 부분만 잘라 읽으므로 메모리가 모자라지 않음
- 갤러리·파일 관리자의 "다음으로 열기", "공유/보내기"(한 장, 여러 장)로도 열 수 있음
- 화면을 한 번 탭하면 위/아래 메뉴 숨기기/보이기. 아래로 읽어 내려가면 메뉴가 저절로 숨겨짐
- 아래 슬라이더로 원하는 위치로 바로 이동, 몇 % 지점인지와 몇 번째 장인지 표시
- 볼륨 키(아래/위)로 한 화면씩 스크롤
- 가로 화면으로 돌려도 가로 폭에 다시 맞추고 보던 위치를 유지
- 마지막으로 보던 이미지와 위치를 기억해서 다음에 켜면 이어 보기
- 지원 형식: JPG, PNG, WebP (안드로이드 버전에 따라 HEIC/AVIF), GIF·BMP(첫 프레임, 통째로 읽음)

## 구조

| 파일 | 역할 |
| --- | --- |
| `TileLayout.kt` | 이미지들을 화면 폭에 맞췄을 때의 높이를 계산하고, 긴 이미지를 화면 높이 정도의 조각으로 나눔. 스크롤 위치 ↔ "몇 번째 장의 몇 %" 변환 (안드로이드 없이 단위 테스트) |
| `NaturalOrder.kt` | 파일 이름을 숫자 크기 순서로 정렬 |
| `PageLoader.kt` | 고른 파일/폴더에서 이미지 목록, 이름, 원본 크기 읽기 |
| `TileDecoder.kt` | `BitmapRegionDecoder`로 조각 하나만 잘라 읽기, 화면보다 훨씬 큰 이미지는 줄여 읽기, 읽은 조각 캐시 |
| `TileAdapter.kt` | 조각 하나 = `RecyclerView` 항목 하나. 높이를 미리 알기 때문에 그림을 읽기 전에도 스크롤 길이가 정확함 |
| `MainActivity.kt` | 파일/폴더 열기, 메뉴 숨기기, 슬라이더, 볼륨 키, 위치 저장 |

핵심 아이디어: 세로 20000px 이미지를 한 번에 비트맵으로 만들면 수십~수백 MB가 필요하고, 화면이 그릴 수 있는 최대 크기도 넘습니다.
그래서 이미지를 화면 높이 정도의 조각으로 나눠 목록처럼 늘어놓고, 화면 근처의 조각만 그때그때 잘라 읽습니다.

## 설치 / 배포

### 휴대폰에 설치하기
1. [Releases](https://github.com/JeongW-C/Meetup/releases) 에서 **웹툰뷰어** 릴리스를 열고 `webtoon-viewer.apk` 를 휴대폰에서 눌러 내려받습니다.
   (main 브랜치에 앱 코드가 올라가면 `webtoon-viewer` 워크플로가 릴리스를 자동으로 만들거나 갱신합니다. 버전 이름은 `app/build.gradle.kts` 의 `versionName`.)
2. 받은 APK를 열면 "출처를 알 수 없는 앱 설치" 허용을 묻습니다. APK를 연 앱(크롬, 파일 앱, 카카오톡 등)에 허용을 켜고 설치하세요.
   Play 프로텍트가 "확인되지 않은 앱" 경고를 띄우면 "무시하고 설치"를 누르면 됩니다.
3. 지인에게는 릴리스 페이지 링크를 보내거나 APK 파일을 직접 전달하면 됩니다.
4. **업데이트**: 모든 빌드가 저장소의 `demo.keystore`로 같은 서명을 하므로, 새 APK를 받아 설치하면 기존 앱 위에 그대로 업데이트됩니다.
   Play 스토어 등으로 널리 배포하려면 데모 키 대신 비공개 서명 키를 쓰세요.

PR이나 다른 브랜치의 빌드는 Actions의 `webtoon-viewer` 실행 페이지에서 `webtoon-viewer-apk` 아티팩트(zip)로 받을 수 있습니다.

### 직접 빌드
Android Studio에서 `webtoon-viewer/` 폴더를 열고 실행하거나, 터미널에서:

```bash
cd webtoon-viewer
./gradlew testDebugUnitTest assembleRelease
# 결과: app/build/outputs/apk/release/app-release.apk
```

요구 사항: JDK 17 이상, Android SDK (compileSdk 35). 최소 지원 버전은 Android 7.0 (API 24).

## 자동 테스트
- 단위 테스트(`app/src/test`): 조각 나누기에 빈틈·겹침이 없는지, 화면 폭이 바뀌어도 같은 위치를 찾는지, 이름 정렬
- 에뮬레이터 스모크 테스트(`scripts/smoke-test.sh`): `samples/` 의 이미지를 열어
  이름 순서 정렬, 손가락/볼륨 키 스크롤, 메뉴 숨기기, 껐다 켰을 때 이어 보기, 가로 화면, 세로 20000px 이미지를 확인하고
  스크린샷을 `webtoon-viewer-screenshots` 아티팩트로 남깁니다.

## 시험용 파일
`samples/` 의 `ep_1.png`, `ep_2.png`, `ep_10.png`(각 720×6000), `long-20000px.jpg`(800×20000)를 휴대폰에 복사해서 열어 보세요.
양쪽 빨간 테두리가 화면 가장자리에 딱 붙어 보이면 가로 폭에 맞춰진 것입니다.
